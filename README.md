# Чуланчик — сайт-визитка

Статический сайт комиссионного магазина «Чуланчик».
Собран на Astro 5, хостится на GitHub Pages.

- **Прод:** https://allikk38.github.io/chulanchik-cite/
- **Репозиторий:** https://github.com/Allikk38/chulanchik-cite

---

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install       # один раз
npm run dev       # запустить dev-сервер (http://localhost:4321/chulanchik-cite/)
npm run build     # собрать прод-версию в dist/
npm run preview   # посмотреть прод-сборку локально
